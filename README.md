🌊 PROJECT VISION

</div>

<p align="center">
<b>Flowey</b> is designed as a premium digital tea storefront that combines an elegant luxury-commerce interface
with practical e-commerce functionality. The application supports product discovery, product details, cart management,
wishlist, checkout, orders, loyalty rewards, a spin wheel, authentication and an admin management experience.
</p>

🚀 QUICK START

</div>

01 — Clone

git clone https://github.com/YOUR_USERNAME/FLOWEY.git
cd FLOWEY

02 — Install dependencies

npm install

03 — Configure environment variables

Create your environment file using the variables required by your local setup.

# Example — use your actual Firebase / database configuration
DATABASE_URL=your_database_url

# Add the Firebase configuration required by your project
# Add any additional application secrets here

🔐 Never commit real credentials, private keys or production secrets to GitHub.

04 — Push the database schema

npm run db:push

05 — Start development server

npm run dev

For separate client development:

npm run dev:all

06 — Production build

npm run build

07 — Start production server

npm start
